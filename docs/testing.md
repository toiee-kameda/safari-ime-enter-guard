# テスト手順

自動テストはありません。Safari で実際に日本語を入力して確かめます。

## 準備
1. 拡張機能を Safari に読み込みます（[README](../README.md) の「ソースから試す」）。
   コードを変えたら、一度外してもう一度読み込みます。
2. テストページを、手元のサーバーで開きます（`file://` で開くと拡張機能が動かないことがあります）。

```bash
cd test && uv run --no-project python -m http.server 8765 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8765/ime-test.html` を開きます。

## テストページ（機能1）

テストページの3つの入力欄は、わざと「`isComposing` だけで判定する」作りにしてあります。
ページ上部に拡張機能のオン／オフが表示されます。ログは再読み込みしても残ります。

| 操作 | 拡張機能オン | 拡張機能オフ |
|---|---|---|
| 「てすと」と入力して Enter で確定 | ログに何も出ない | 「送信」が出る（`keyCode=229`） |
| 続けてもう一度 Enter | 「送信」が出る | 「送信」が出る |

## 実際のサイト（機能2）

ツールバーのボタンから、そのサイトにチェックが入っていることを確かめてから試します。

1. 日本語を入力し、Enter で確定する → 送信されない
2. 確定してすぐ Enter を押す → 1回で改行が1行分だけ入る
3. ⌘+Enter → 送信される
4. 本物の Shift+Enter → 改行される（サイト本来の動き）
