# Claude Code 用プロンプト例

プロジェクトフォルダで `claude` を起動してから使います。

## 1. 最初の把握
```
CLAUDE.md と extension/ 以下を読んで、この拡張機能の仕組みを非エンジニア向けに3〜5行で説明してください。そのうえで、問題がありそうな箇所があれば指摘してください。まだコードは変更しないでください。
```

## 2. 動作確認の手順づくり
```
Safari 27 に一時的な拡張機能として読み込み、test/ime-test.html で動作確認する手順を、クリックする場所がわかるように番号付きで教えてください。拡張機能のオン／オフで結果がどう変わるべきかも書いてください。
```

## 3. 不具合の報告と修正
```
test/ime-test.html の「3. contenteditable」で、日本語を確定しただけで送信されてしまいました。ログには次のように出ています：
（ここにログを貼る）
原因の仮説を挙げてから、content.js を修正してください。修正後に私が確認すべきことも教えてください。
```

## 4. 対象サイトの追加
```
（サイト名・URL）でも ⌘+Enter 送信を使いたいです。SITES に追加してください。入力欄の作りがわからない場合は、私が Safari の Web インスペクタで調べる手順を教えてください。
```

## 5. 送信が効かないサイトへの対応
```
claude.ai で ⌘+Enter を押しても送信されません。合成イベントが無視されている可能性があります。送信ボタンをクリックする方式に切り替える案を、サイト別設定として実装してください。
```

## 6. 常用できる形にする（アプリ化）
```
一時的な拡張機能では Safari を終了するたびに外れて不便です。xcrun safari-web-extension-converter を使って、この Mac だけで使えるアプリにする手順を案内し、必要なコマンドを実行してください。有料の Apple Developer Program なしでできる方法でお願いします。
```

## 7. Git 管理
```
このフォルダを git で管理したいです。.gitignore を用意して最初のコミットをしてください。
```
