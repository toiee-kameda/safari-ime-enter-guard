# プライバシーポリシー / Privacy Policy

最終更新: 2026-10-30

## 日本語

IME Enter Guard（以下「本拡張機能」）は、利用者の個人情報を収集しません。

### 収集しない情報
- 入力した文字、閲覧したページの内容や URL、閲覧履歴
- 利用状況の統計、クラッシュ情報、広告用の識別子

本拡張機能は、外部のサーバーと通信しません。

### 保存する情報
- 「Enter＝改行、⌘+Enter＝送信」を有効にしたサイトのホスト名の一覧（例: `claude.ai`）

この一覧は、Safari の拡張機能用ストレージ（`storage.local`）に保存され、お使いの Mac の外には送られません。
拡張機能を削除すると、一緒に削除されます。

### Web サイトへのアクセス許可について
本拡張機能は、すべてのサイトでキーボードの Enter キーを処理するため、Safari から「Web サイトへのアクセス」を求めます。
この許可は Enter キーの処理だけに使い、ページの内容を読み取ったり保存したりはしません。

### お問い合わせ
GitHub リポジトリの Issues からご連絡ください。

## English

IME Enter Guard ("the extension") does not collect any personal information.

- It does not collect what you type, page contents, URLs, or browsing history.
- It does not collect analytics, crash reports, or advertising identifiers.
- It does not communicate with any external server.

The only data stored is the list of host names where you enabled
"Enter = newline, ⌘+Enter = send" (for example, `claude.ai`).
This list is kept in Safari's extension storage (`storage.local`) on your Mac
and is removed when you uninstall the extension.

The extension asks for access to websites only so that it can handle the Enter key
on every site. It does not read or store page contents.

For questions, please open an issue on the GitHub repository.
